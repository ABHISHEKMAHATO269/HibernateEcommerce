# Hibernate Ecommerce

A console-based e-commerce application developed using Java, Hibernate ORM, Maven, and MySQL.

## Technologies

- Java
- Hibernate ORM
- JPA
- Maven
- MySQL
- BCrypt
- Eclipse IDE

## Project Structure

├── src/main/java
